csagent

Agent d'assistance au codage autonome multi-plateformes

Présentation

csagent est un agent d'assistance au codage autonome, écrit en C# (.NET 8), conçu pour aider les agents de l'administration à automatiser leurs tâches de développement informatique.

Attention : Cette solution est spécifiquement destinée aux agents de l'administration qui ne peuvent pas utiliser les LLM du marché (comme ChatGPT, Claude, etc.) en raison de contraintes de sécurité ou de confidentialité.

Contrairement aux solutions basées sur des LLM publics, csagent peut être configuré pour utiliser des modèles locaux ou privés, garantissant ainsi la protection des données sensibles.

Fonctionnalités principales

  • Multi-plateforme : Fonctionne sous Windows, Linux et macOS
  • Interaction avec les LLM : Communique avec tout LLM compatible OpenAI (par défaut : Qwen3-Coder via ALBERT/Etalab)
  • Gestion de fichiers : Lecture et écriture de fichiers, exploration de répertoires
  • Exécution de commandes : Exécution de commandes shell avec gestion des retours
  • Sessions persistantes : Historique de conversation stocké dans un fichier JSON
  • Sécurité : Modes dry-run et confirm pour prévisualisation et validation

Utilisation

La commande de base est la suivante :

csagent <fichier-mémoire> [<prompt-ou-fichier>] [options]

Arguments

Argument Description
fichier-mémoire Chemin vers le fichier JSON stockant l'historique de conversation. Créé automatiquement lors de la première exécution.
prompt-ou-fichier Description de la tâche (sous forme de chaîne), ou chemin vers un fichier texte contenant le prompt. À omettre pour continuer une session précédente.

Options

Option Description
--dry-run Affiche les appels d'outils mais ne les exécute pas (aperçu sécurisé).
--confirm Demande une confirmation Y/n avant chaque exécution de commande shell ou écriture de fichier.
--max-steps N Nombre maximum d'itérations de l'agent (par défaut : 30).
--model NOM Remplace le modèle LLM utilisé (par défaut : Qwen/Qwen3-Coder-30B-A3B-Instruct).
--endpoint URL Remplace l'URL de base de l'API.
--help Affiche l'aide d'utilisation.

Exemples d'utilisation

Première exécution - création de mémoire et attribution d'une tâche

csagent.exe memory.json "Écrire un serveur HTTP Python qui sert le répertoire courant."

Chargement d'une tâche depuis un fichier

csagent.exe memory.json task.txt

Reprise d'une session précédente

csagent.exe memory.json

Aperçu de ce que l'agent ferait (pas d'exécution)

csagent.exe memory.json "Refactoriser main.py" --dry-run

Demande de confirmation avant chaque action

csagent.exe memory.json "Nettoyer tous les fichiers .tmp" --confirm

Utilisation d'un modèle différent (GPT-4o)

csagent.exe memory.json "Ajouter des tests unitaires" \ --model gpt-4o \ --endpoint https://api.openai.com/v1

Outils disponibles

L'agent peut utiliser les outils suivants :

Outil Description
write_file(path, content) Créer ou écraser un fichier texte UTF-8. Les répertoires parents sont créés automatiquement.
read_file(path) Lire et retourner le contenu d'un fichier. Refuse les fichiers > 512 Ko.
list_dir(path?, recursive?) Lister les fichiers et sous-répertoires.
sh(cmd) Exécuter une commande shell (cmd.exe sur Windows, /bin/sh ailleurs). Timeout de 60 secondes. Le code de sortie est rapporté au modèle.

Configuration

Prérequis

  • SDK .NET 8 — https://dotnet.microsoft.com/download
  • Une clé API pour un endpoint compatible OpenAI
  • Par défaut : [ALBERT (Etalab)](https://albert.api.etalab.gouv.fr) — ALBERT_API_KEY
  • Ou tout autre API compatible OpenAI — OPENAI_API_KEY

Configuration de la clé API

# Linux / macOS export ALBERT_API_KEY=your-key-here # Windows (cmd) set ALBERT_API_KEY=your-key-here # Windows (PowerShell) $Env:ALBERT_API_KEY = "your-key-here"

Sécurité

Attention : La commande sh exécutera toute commande que le modèle décidera de lancer.
  • Utilisez --confirm lors de l'exécution dans un espace de travail sensible.
  • Utilisez --dry-run pour auditer une session avant exécution.
  • Ne stockez jamais votre clé API dans memory.json ou tout fichier suivi.
  • Gardez le fichier de mémoire hors des répertoires contenant des secrets.

Intérêt dans le cadre de l'assistance au codage

csagent est particulièrement utile pour les agents de l'administration car il permet :

  • Automatisation des tâches répétitives : Génération de code, nettoyage de fichiers, configuration de projets
  • Protection des données : Utilisation de modèles locaux ou privés sans transmission de données vers des services externes
  • Collaboration sécurisée : Capacité à travailler dans des environnements restreints où les LLM publics ne sont pas autorisés
  • Prise en charge multi-plateforme : Fonctionne identiquement sur Windows, Linux et macOS
  • Contrôle total : Mode dry-run et confirmations permettent de valider chaque action avant exécution
Note : Contrairement aux solutions basées sur des LLM publics, csagent est conçu pour fonctionner dans des environnements où l'accès aux services cloud est restreint ou interdit, ce qui est fréquent dans les administrations publiques.
